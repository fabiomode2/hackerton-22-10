# Notas entre agentes

Memoria del equipo. Aquí va **lo que no se deduce leyendo el código**: decisiones, trampas, atajos, cosas que costaron 20 minutos y no queremos volver a descubrir.

## Reglas

- **5 bullets máximo** por nota. Si no cabe, es una decisión: va a `docs/decisions/`.
- Escribir **mientras se trabaja**, no al final.
- Formato: `Qué probé / Qué funcionó / Qué NO / Gotcha / Siguiente`.
- Si tu nota ahorra 10 minutos a otra persona, escríbela. Si no, no llenes el repo.
- Enlaces a líneas de código concretas, no a "el archivo".
